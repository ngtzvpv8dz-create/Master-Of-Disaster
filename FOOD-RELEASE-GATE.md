# v1 release gate

All changes go to a test branch and a pull request. Run all existing applicable automated checks, including Chromium, WebKit and Firefox, against the exact candidate commit. Do not merge if a check is failing, pending or missing. Repair root cause and rerun after each candidate change. Tests use synthetic fixtures, never production credentials. Verify database changes separately with transactional rollback and the authenticated role. Do not describe synthetic browser tests as an authenticated production test. Verify deployment and relevant production read-only views separately. Explicitly document any missing coverage, required permission, and deployment blocker. Branch protection must be configured in GitHub repository settings to enforce these conditions; this document alone is not an enforcement mechanism.

All 12 pre-merge workflows are triggered on every pull request to main, irrespective of changed paths. The 3 existing public Pages smoke checks remain post-deployment; scheduled metrics and maintenance workflows are not pre-merge tests. The release-aware cache test helper is shared across all three former static-version assertions. A live authenticated check is a separate requirement, not covered by fixture tests.
